## 📐 Design Philosophy

* **70% Editorial** — High-contrast typography, asymmetrical grids, architectural balance, and generous whitespace.
* **20% Digital** — Responsive layouts, fluid scaling, interactive preview drawers, and device toggles.
* **10% Experimental** — Tactile micro-interactions, dark aesthetic, and sharp contrast systems.
